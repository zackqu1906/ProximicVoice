# Device protocol source

`src/ring_python_sdk` is an unmodified local snapshot of the Ringo SDK supplied
with `/Users/admin/Downloads/ProximicVoice-main/src/ring_python_sdk`.
It is copied so this project does not import Proximic's ASR, detector, or UI.
No standalone license was present in the supplied SDK. Its upstream source
and redistribution terms are those documented by the original device project;
this local training project does not grant additional distribution rights.

NumPy, SciPy, PySide6, Bleak, cryptography and opuslib are installed dependencies
and retain their respective upstream licenses. Native libopus is not bundled;
the launcher can reuse an existing local installation.
