# 输入范围与撤销记录

2026-09-19：将听写的原文快照、实时组合范围和定稿范围分别管理。不是按应用名或某个光标偏差值放行。

- `original` 是输入前的原文／选区快照，用于原文恢复和编辑上下文。定稿坐标变化不能重写这份快照。
- 未定稿时以当前组合范围作为写入位置。若坐标原点变化，原始选区和组合范围必须独立一致，并符合已经识别的选区语义、当前文字长度和同一激活会话。
- 适配器保留 `reportedSelection`。不能先用组合范围修正选区，再拿这个修正结果当作组合范围正确的独立证据。
- 所有组合提交经过 `acknowledgeOwnedCommit`：确认组合结束、采样前后选区一致，并读取本次文字所在的局部范围。下一步使用客户端确认的实际位置。
- `committedRange` 单独保存已确认的听写范围，撤销栈也记录这个范围，不再一律从开始听写时的选区推算。无需查找全文，也不添加固定等待或后台轮询。
- 无法确认本次文字时不开放对应范围的删除。旧位置仍有相同句子时，不能自动改认光标附近的另一句；键盘、鼠标和输入框切换仍会结束当前归属。
- 文案：听写与收尾期间“取消”，定稿后“撤销”，编辑完成后“还原听写”。

回归覆盖：连续 partial 的坐标原点变化、定稿的坐标变化、未定稿取消、保留前后文的撤销、多次撤销、不可读／错误文本、前面存在相同句子但光标被移动、原始选区与错误组合范围不一致。原生客户端由本地 AppKit 文本控件模拟，真实 Codex 等应用仍需用户体验核对。

## 2026-09-20：听写不等待光标确认

以下规则替代上文对普通听写的光标一致性要求，适用于所有生产 macOS 输入客户端，不按应用名区分。

- 未定稿更新仍确认组合范围及长度，但不要求光标处于推算的句末或锚点；连续 partial 不再仅因光标回读异常进入等待。
- 原生提交后确认组合已结束即可完成听写。光标暂不可读、坐标原点改变或局部范围不可读，不再把已完成的输入判为定稿失败。
- 仅在范围与文字可确认时保留本句删除能力；无法确认时保留听写结果，不开放不确定范围的撤销。定稿后停止基于轮询光标的归属检查。
- 真实鼠标、键盘和输入框激活变化仍立即使旧事务失效；编辑替换、原文恢复、撤销仍验证操作内容和范围。

新增回归：Codex、微信、VS Code、通用客户端返回过期、越界或不可读光标时持续输入、定稿及开启下一句。原文保护、多次撤销、焦点切换和异步回调重入回归仍通过。
