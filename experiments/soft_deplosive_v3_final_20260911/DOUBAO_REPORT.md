# 柔和 De-plosive v3：豆包 SeedASR 对比

## 结论

柔和 v3 有效降低了低频喷麦，同时保持了 300 Hz 以上的语音主体；但这 5 条样本没有显示出稳定的豆包 ASR 准确率提升。

- 第 3–5 条：原始版和 v3 版均返回空文本。
- 第 6 条：原始版和 v3 版均为 `12345。`。
- 第 7 条：本次原始重放为 `什么时候等不了。`，v3 为 `什么时候到达？等量？`；历史在线结果曾为 `什么时候到达不了？`，说明单次云端输出存在波动，不能把本次变化认定为净改善。

## 算法

1. 以 16 ms 窗口、4 ms hop 检测 20–300 Hz 相对约 260 ms 局部中位数基线的瞬时上升。
2. 使用 513-tap Blackman FIR 在 130 Hz 附近构造互补低频支路；高频支路为 `original - low`。
3. 仅对低频支路动态衰减 4–7 dB，高频和辅音信息不做压缩。
4. 使用 18 ms 预启动、20 ms 保持和 120 ms 余弦恢复，避免 v2 的快速全频增益跳变。
5. 不尝试伪造已经削顶的波形。后处理无法可靠恢复 ADC/编码前已经丢失的峰值，激进插值会重新引入“差麦克风”质感。

## 判断边界

这版可作为“柔和降低喷麦听感”的候选，但当前证据不足以把它接入正式 ASR。第 3–5 条即使压低低频仍为空，表明空识别并非单纯由低频电平造成；应优先在麦克风 ADC 或 Opus 编码之前降低采集增益，避免失真先被写入音频。
