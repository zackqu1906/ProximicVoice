# Soft de-plosive v3 A/B test

每条 A/B 音频均为原始版在前、0.5 秒静音、柔和修复版在后。

## Algorithm

- 16 ms / 4 ms hop 检测 20–300 Hz 相对局部基线的瞬时上升。
- 513-tap Blackman 窗 FIR 在 170 Hz 附近做互补分频。
- 只衰减低频支路，7–12 dB；高频支路始终保留原始信号。
- 18 ms 预启动、20 ms 保持、120 ms 余弦恢复，无全频压缩、无固定高通。
