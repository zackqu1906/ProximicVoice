# 编辑提示词精简与灵活改写

按用户要求，让整体编辑充分执行扩写、改写、润色、翻译和排版，同时保留局部增删替换、释字、近音纠错和字母拼写。生产改动只有 `prompts.py` 与 `edit_tool.py` 的提示词及工具说明；没有新增分类器、字数硬校验、模型请求或重试，现有双协议竞速规则未改。运行中的源码程序需重启加载静态提示词；输入法组件不需要重装，本轮未更新 DMG。

最终片段提示词从 1,712 字符缩短到 1,482，全文提示词从 1,556 缩短到 1,309。移除密集的细项约束与百分比字数区间，明确整体编辑可以重组和展开。工具参数说明不再将“片段”解释为不能返回全文；只修改重复项中的一处时返回全文范围，避免程序的全匹配替换误伤其他出现位置。

验证使用当前配置的 `deepseek-v4-flash-260425`，输入全部为合成案例，不操作任何真实文本框。凭据仅保留在进程内，报告不含凭据。字数范围只是实验观察指标，不是生产拦截条件；自动检查通过不等于语义无误。

人工阅读还发现：扩写样例会补出未提供的产品功能，数字描述偶有语义错误，故事往往超出目标字数。这些局限明确保留在报告中，没有靠删除失败样例或增加生产硬拦截制造全通过结果。此次优先满足灵活编辑与现有操作能力，不能承诺精确字数或事实扩写绝对可靠。

78 项现有代码回归通过，覆盖模型调用、双协议处理、增删替换与状态流程。唯一测试调整是兼容精简后的 ASR 纠错规则措辞；没有将模拟返回当成模型能力证明。

复验入口为 `evaluate.py`，必须显式运行才会调用配置的在线模型。`--case` 可以限定案例，`--baseline` 添加旧提示词对照，`--output` 必须指定未存在的文件以保留历史结果。全部原始输出、各轮提示词及哈希随 JSON 记录保存。
